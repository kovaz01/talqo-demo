    Talqo Embeddable Widget

    This is the drop-in chat widget that your customers can add to any website with a single script tag. Click the chat bubble in the bottom-right corner to try it.

    Embed Code
    <script src="https://talqo-api.onrender.com/widget.js"></script>
<script>
  // Chat mode (explicit channel & user)
  Talqo.init({
    apiKey: 'YOUR_API_KEY',
    channelId: 'YOUR_CHANNEL_ID',
    userId: 'visitor-123',
    theme: 'light',
    position: 'bottom-right'
  })

  // Support mode (auto guest ID & channel)
  Talqo.init({
    apiKey: 'YOUR_API_KEY',
    mode: 'support',
    theme: 'light'
  })
</script>
