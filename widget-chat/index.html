Talqo Widget

Add chat or support to any website with a single script tag. No framework required — works on any HTML page.

Choose a mode

Chat Mode — Connect to a specific channel. Shows message history. Best for community chat, team channels, or in-app messaging.

Support Mode — Auto-creates a private 1:1 conversation. Collects visitor name via pre-chat form. Conversations appear in your dashboard inbox.

Click "Launch Widget" to try it

Embed Code

Copy this into your HTML — that's it. No build tools needed.

// Chat mode — connect to a specific channel <script src="https://talqo-api.onrender.com/widget.js"></script> <script> Talqo.init({ apiKey: 'YOUR_API_KEY', channelId: 'YOUR_CHANNEL_ID', userId: 'user-123', userName: 'John Doe', theme: 'light', position: 'bottom-right' }) </script>
// Support mode — auto-creates private conversation <script src="https://talqo-api.onrender.com/widget.js"></script> <script> Talqo.init({ apiKey: 'YOUR_API_KEY', mode: 'support', position: 'bottom-right' }) // Visitor enters name via pre-chat form // Conversation appears in your dashboard </script>

How it works

1. The widget script loads from your Talqo API server

2. Talqo.init() creates a Web Component with Shadow DOM (isolated styles)

3. Connects via WebSocket for real-time messaging

4. In support mode: collects visitor name → creates private channel → agent sees it in dashboard
